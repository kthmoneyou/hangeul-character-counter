# 한눈에 글자수

한글 텍스트를 입력하면 바로 공백 포함·제외 글자수를 보여주는 무료 웹 도구입니다. 모바일과 데스크톱에서 로그인 없이 사용할 수 있습니다.

## 기능

- 공백 포함 / 공백 제외 실시간 글자수
- 공백으로 구분한 단어 수, 줄 수, UTF-8 바이트 수
- 글 전체 복사, 전체 지우기, 지우기 되돌리기
- 한국어 입력 조합 및 이모지 글자 단위 계산
- 외부 의존성, 분석 추적, 입력문 서버 전송 및 저장 없음

## 실행 및 검증

`npm start`로 로컬 서버를 실행하고 http://127.0.0.1:4173 에 접속합니다. Python 3가 필요합니다. `npm test`로 계산 로직을 검사합니다(Node.js 18 이상).

별도 빌드 없이 GitHub Pages의 `main` 브랜치 루트에서 게시합니다.

## 계산 기준

`Intl.Segmenter`를 지원하는 브라우저에서는 눈에 보이는 문자(grapheme) 단위로 계산합니다. 지원하지 않으면 NFC 정규화 후 유니코드 코드 포인트로 계산하므로 복합 이모지의 결과가 다를 수 있습니다. CRLF와 CR은 글자수 및 줄 계산 시 LF로 통일하며 바이트는 원문 UTF-8 기준입니다. 공백 제외는 JavaScript의 `\s`에 해당하는 공백·탭·줄바꿈 등을 제외합니다. 제출처의 계산 기준과 다를 수 있습니다.

입력한 글은 메모리에만 존재하며 새로고침 시 사라집니다.
